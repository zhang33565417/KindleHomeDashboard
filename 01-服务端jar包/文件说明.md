# 服务端文件说明

| 文件/目录 | 作用 | 需要操作吗？ |
| --- | --- | --- |
| `kindle-home-dashboard.jar` | 完整服务程序：提供手机/电脑管理网页、保存记录、获取天气、生成 Kindle 图片。 | 安装 Java 17 后运行。不要复制到 Kindle。 |
| `文件说明.md` | 本说明。 | 首次使用先阅读。 |
| `data/`（运行后才生成） | 设置、安排、胎动记录、天气缓存和生成图片。 | 备份时保留，公开分享时不要上传。 |

## 怎么启动

在这个文件夹里打开终端，确认 `java -version` 显示 Java 17，然后执行：

```sh
java -jar kindle-home-dashboard.jar --server.address=0.0.0.0 --server.port=8080
```

电脑打开 `http://127.0.0.1:8080`。手机和 Kindle 连接同一家庭 Wi-Fi，使用电脑的局域网 IP，例如 `http://192.168.1.100:8080`。配置城市、预产期和横竖屏分辨率。

窗口需保持运行，Ctrl+C 停止。请固定在这个目录启动，否则默认 `data/` 位置会改变。电脑休眠/关机后不会更新内容。程序无内置登录，只在可信家庭网络使用，不直接开放公网。

详细配置、字体与备份，见 [项目 README](../README.md)。
